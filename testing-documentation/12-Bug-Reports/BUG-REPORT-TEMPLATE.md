# Writing a reproducible defect record

[BUG-01](BUG-01.md) is the completed example from this campaign. It records the observed environment, two executable API cases, the expected HTTP 400 result, the actual HTTP 200 result, and the linked fix and retest. Its severity reflects the impact on published recipes. Its priority reflects the need to align the API with the browser form ahead of the campaign. Preserve both failing and passing evidence when adding another defect.
